### 🚀 Highlighted Projects

#### 1. 🔐 [Enterprise Spring Security Template](https://github.com/amarenderreddyvoladri/production-prototype-security-template)
> **Production-Grade Authentication, Authorization & Identity Management Microservice**

A production-ready security blueprint built to establish robust security for enterprise web systems (HRMS, Fintech, and SaaS).

*   **Immutable Identity Claiming:** Uses `userId` as the JWT subject instead of the username to ensure username-change-safety.
*   **Dual-Layer Authorization:** Employs role-based endpoints and granular, DB-backed permissions mapped directly to methods using `@PreAuthorize`.
*   **Session Control & Token Rotation:** Features DB-tracked active sessions, token type guards (blocking refresh tokens from API access), individual session revocation, and automated token cleanup using Spring Scheduler.
*   **Brute-Force & Account Lockout:** Integrates a Redis-backed login attempt counter that locks accounts temporarily, triggering audit events.
*   **Secure OTP Workflows:** Handles registration and password reset via TTL-capped OTPs saved in Redis and dispatched via SendGrid.
*   **Production Auditing:** Writes a full, non-blocking audit trail (`REQUIRES_NEW` transactions) tracking user, action, IP, device, and request status.
